# Катя — твоё время

Цифровой квест ко дню рождения. Статический сайт: HTML, CSS и JS, без сборки.

## Как открыть локально

Открой `index.html` в браузере или подними простой сервер в папке проекта:

```bash
python3 -m http.server 8765
```

Дальше: [http://localhost:8765](http://localhost:8765)

## Публикация на GitHub Pages

1. Создай репозиторий на GitHub и залей эту папку.
2. **Settings → Pages**
3. Source: **Deploy from a branch**
4. Branch: `main`, folder: `/ (root)`
5. Save

Сайт откроется по адресу:

`https://<username>.github.io/<repo>/`

QR-код можно вести на этот URL. Пока имя аккаунта и репозитория не меняются, ссылка остаётся той же.

## Структура

| Файл | Зачем |
|---|---|
| `index.html` | Квест: три вопроса |
| `moments.html` | Главы, карта воспоминаний, подарок |
| `dc-theme.css` | Стили |
| `flowers.js` | Цветы на экранах |
| `memories.js` | Фото для карты воспоминаний |
| `photos/` | Снимки (имя файла = год и событие) |
| `ТЕКСТЫ.md` | Все текстовки для правок |

Фото: положи файлы в `photos/` в формате `2021_Название события.jpeg`. Если года или названия нет — оставь поле пустым в имени, на карточке оно тоже будет пустым.
